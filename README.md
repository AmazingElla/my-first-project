## 1. Student Grade Checker

### Description

This Python program accepts a student's name and score, validates the score, and determines the student's grade based on the grading system below.

### Grading System

* 70–100 → A
* 60–69 → B
* 50–59 → C
* 45–49 → D
* 40–44 → E
* 0–39 → F

Scores below 0 or above 100 are considered invalid.
