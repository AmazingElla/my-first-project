# 🐍 Python Practice Exercises

This repository contains beginner-friendly Python exercises I completed while learning **Python programming and problem-solving**.

## 📚 Exercises

* **Student Grade Checker** — Uses conditions to validate scores and assign grades.
* **Electricity Bill Calculator** — Calculates bills based on electricity usage.
* **ATM Withdrawal** — Checks withdrawal conditions and calculates the remaining balance.
* **Restaurant Bill Calculator** — Calculates a restaurant bill, adds a 25% tip, and divides the cost among 4 people.

## 🧠 Concepts Practiced

* Variables
* `input()` and type conversion
* Arithmetic and comparison operators
* `if / elif / else`
* Logical operators
* Input validation
* Loops
* f-strings
* Basic problem-solving

**Goal:** Understand the problem → break it down → write the code → test the solution.
