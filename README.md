# Student Grade Checker

## Description

This Python program accepts a student's name and score, then determines and displays the student's grade based on the grading system below.

### Grading System

* 70–100 → A
* 60–69 → B
* 50–59 → C
* 45–49 → D
* 40–44 → E
* 0–39 → F

## What I Practiced

* Using `input()` to receive user information
* Converting user input from a string to an integer using `int()`
* Storing information in variables
* Using `if`, `elif`, and `else`
* Using comparison operators
* Storing the result in a variable
* Using f-strings to display the result

## Example

```text
Enter student's name: Alice
Enter score: 75
Student: Alice, Grade: A
```
